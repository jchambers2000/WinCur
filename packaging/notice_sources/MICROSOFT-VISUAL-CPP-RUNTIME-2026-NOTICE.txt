Microsoft Visual C++ v14 Runtime Components
============================================

WinCur's portable Windows distribution includes the following Microsoft
Visual C++ release-runtime DLL families required by CPython, PySide6, and Qt:

  MSVCP140.dll
  MSVCP140_1.dll
  MSVCP140_2.dll
  VCRUNTIME140.dll
  VCRUNTIME140_1.dll
